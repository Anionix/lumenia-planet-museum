# 15画像の公開レビュー

課題: https://github.com/Anionix/lumenia-planet-museum/issues/11

固定比較は a13dfe25561b12b1c49ea3a12ec7ea4abd453d13 から 5153523dcfb9eb99a9770818453348787995a4d4。

## 規則

15画像と登録した依存ファイルの照合値が一致した。「物理を含まない」とする既存の描画契約は更新し、独立した画像操作ページでのみ、利用者が有効にした後の物理を認める。公開された操作用ファイルも原本と同じであることを検査する。

## 仕様

公開フォルダで開発用コマンドを案内していた問題を修正した。公開用の説明は GitHub の実行手順と、固定した改訂の Lean・Wolfram 記録を参照する。コピー元のローカル起動処理も、移設先のフォルダ名を使うようにした。

画像は新しく生成していない。登録された15原画像、12件の特徴座標、3件の未設定値、物理の標準無効を保持する。画像の公開は自由探索の完成を意味しない。後続の課題12・13で、画像の中の球・環・建物を立体化する。

同梱したライブラリは版・ライセンス・照合値を記録し、GitHub では vendor 差分を折りたたむ。手書きの公開処理と資料の判断を優先してレビューできる。
