# 課題の保存先

GitHub: https://github.com/Anionix/lumenia-planet-museum/issues

課題の追加と変更提案の送信、既存 Sites と Vercel への公開は、現在の目標で利用者が許可している。既存の課題と変更提案を参照し、重複した課題を作らない。課題間の依存は本文の「前提」に記録する。状態と完了の証拠は実際の変更と公開結果を読み直して確認する。

利用者の作業を含む元の作業場所と sources は保全する。後から利用者が許可した「15分間コメントがなければ統合可能」を適用する。最新の対象コミット、検査、未解決の指摘、レビュー実行状態を確認してから統合する。残る作業と依存関係は [verification-tasks.jsonl](verification-tasks.jsonl) に記録する。
