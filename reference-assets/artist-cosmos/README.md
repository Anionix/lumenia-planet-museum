# 作家と宇宙を組み合わせた15枚

[index.html](index.html)で15枚を一覧・拡大表示できます。各画像は独立した1536×1024の画像ファイルです。

参照資料: `planetarium/illustration-design-reference.jsonl`。15人の視覚的特徴、12人の素材球の提案、根拠と一次資料をたどり、各人の形・素材・配色と宇宙の表現を組み合わせました。宇宙との組み合わせは今回の創作です。

すべてChatGPTの組み込み画像生成で個別に生成しました。

- `references.jsonl`: 画像、生成指示、資料レコードとの対応、一次資料、保存と目視確認の記録。
- `art-direction-briefs.jsonl`: 再利用できる生成指示と参照した資料の抜粋。
- `state-transitions.jsonl`: 時刻と識別子を伴う状態の記録。
- `validation.json`: 15枚の独立性、サイズ、資料への対応と保存の確認結果。
